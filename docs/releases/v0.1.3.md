# Hngoos Download Manager v0.1.3

Preferences rendering fixes for rapid appearance and language changes.

- Draw preferences labels, icons, checkboxes and choices on one shared background.
- Replace each scene together after layout and translation finish, retaining artwork until its replacement is ready.
- Keep the latest selection for each setting when clicks arrive faster than the interface can update.
- Preserve folder selection, native text editing, keyboard navigation and navigation back to downloads.
- Support the Tk versions bundled with Python 3.11 and 3.13 on Windows and macOS.

Existing users can update through **Preferences → Check for update**.
Update metadata is signed with the existing publisher key, and installer downloads are verified with SHA-256.
