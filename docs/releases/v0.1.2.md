# HDM v0.1.2

This update applies the new monochrome HDM logo throughout the application.

- Desktop window and dialog icons, sidebar branding and the system tray.
- Windows executable, setup wizard, shortcuts and installed-app entry.
- macOS app bundles and Linux desktop integration.
- Chromium extension toolbar, management page and popup.

The logo keeps the supplied H, a 100×100 foreground square and a 150×150 rear
square. Platform icon files are generated from the same approved SVG artwork.

## Install

Download the package for your operating system below and run the installer.
For the browser extension, extract `HDM-Browser-Extension.zip`, enable Developer
mode on your browser's extensions page, and choose **Load unpacked**. Existing
unpacked installations can replace the files in their current folder and reload
the extension.

Windows supports Windows 10/11 x64. The macOS and Linux editions remain desktop
previews; see [platform support](https://github.com/hngoos/hngoos-download-manager/blob/main/docs/PLATFORMS.md)
for requirements and limitations. Mobile applications are planned.

The Windows installer has no Authenticode certificate. macOS bundles use ad-hoc
signatures; they are not notarized. The signed update manifest and SHA-256 hashes
below verify release integrity separately from operating-system certificates.
