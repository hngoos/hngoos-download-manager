# HDM v0.1.1

HDM now provides separate desktop installation packages for Windows, macOS and Linux.

| Platform | Package | Installation |
| --- | --- | --- |
| Windows 10/11 x64 | `HDM-Setup-0.1.1.exe` | Run the setup wizard. |
| macOS Apple Silicon | `HDM-0.1.1-macOS-arm64.dmg` | Open the image and drag HDM to Applications. |
| macOS Intel | `HDM-0.1.1-macOS-x64.dmg` | Open the image and drag HDM to Applications. |
| Ubuntu/Debian x64 | `HDM-0.1.1-Linux-x64.deb` | Open with the package installer or use `sudo apt install ./HDM-0.1.1-Linux-x64.deb`. |
| Other Linux x64 desktops | `HDM-0.1.1-Linux-x64.AppImage` | Make executable with `chmod +x`, then run. |
| Chromium browsers | `HDM-Browser-Extension.zip` | Extract, enable Developer mode, and choose Load unpacked. |

## Browser extension

Install HDM first. Extract the extension ZIP to a permanent folder. In your
browser, open its extensions page (`chrome://extensions`, `edge://extensions`
or `brave://extensions`), enable **Developer mode**, select **Load unpacked**,
and choose the extracted folder containing `manifest.json`. Copy its extension
ID into HDM's **Browser** tab and register the connection. Keep the folder
after installation; moving it can change the unpacked extension's ID.

## Changes

- Native DMG packages for both macOS architectures; the browser bridge travels
  inside HDM.app when it is copied to Applications.
- Linux DEB and AppImage packages with desktop integration and bundled runtimes.
- Persistent native host launchers for AppImage installations.
- CMD installation and a Scoop manifest on Windows; source installation remains
  available on macOS and Linux.
- Preliminary inspection of Linux binaries, macOS binaries and executable scripts.
- Explicit platform differences for Windows-only Defender, DPAPI and power actions.

The macOS/Linux editions remain early desktop previews. Packages include their
runtime dependencies; users do not need to install Python. The DEB and AppImage
target x64 desktops with glibc 2.35 or later. macOS packages are tested on macOS 15.
The Windows installer has no Authenticode certificate. macOS bundles have local
ad-hoc signatures, not Developer ID signing or Apple notarization; Gatekeeper
may require explicit approval to open them. Ed25519 update metadata and SHA-256
checks are separate from operating system publisher certificates.

Chrome Web Store publication is pending; use the ZIP for manual extension
installation. Mobile applications are planned for later development.
