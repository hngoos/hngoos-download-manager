# Hngoos Download Manager v0.1.1

Windows repaint fixes and maintenance updates.

- Avoid blank panels and partially drawn controls when clicking the HDM logo repeatedly or changing between light and dark appearance on Windows.
- Keep appearance/language selections and proxy buttons synchronized.
- Start media downloads without probing inaccessible JavaScript runtime paths.
- Restart partial downloads when the source URL changes, preventing mixed content.
- Preserve compatible audio when choosing video streams.
- Clear application history/settings on uninstall, while preserving downloaded files and retaining history during upgrades.

Existing users can install this version through **Preferences → Check for update**.
Update metadata is signed with the existing publisher key and installer downloads are verified with SHA-256.
