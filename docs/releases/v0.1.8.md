# HDM v0.1.8

- Paste a link and press **Enter** to reveal its filename, destination and relevant advanced options beneath the URL bar.
- Click **Download** when ready. Clipboard detection fills the bar without starting a transfer.
- Use **Check Safety** beside a completed file for local checks, Windows Defender and optional VirusTotal multi-engine results.
- VirusTotal requires your personal API key; full-file submissions require separate confirmation. Unknown and pending results are shown explicitly.
- Find Language, Preferences, Browser extension, support and updates in **Info**.
- Includes the Windows update fix for missing Python DLL errors.

Choose your operating system's installer. Mobile is coming soon.
