# Hngoos Download Manager v0.1.0

The first release of the current HDM application for **Windows and macOS**.

## Downloads

- [Windows 10/11 x64 installer](https://github.com/hngoos/hngoos-download-manager/releases/download/v0.1.0/HDM-Setup-0.1.0.exe)
- [macOS Apple Silicon](https://github.com/hngoos/hngoos-download-manager/releases/download/v0.1.0/HDM-0.1.0-macOS-arm64.dmg)
- [macOS Intel](https://github.com/hngoos/hngoos-download-manager/releases/download/v0.1.0/HDM-0.1.0-macOS-x64.dmg)

## Included

- Parallel, resumable downloads with up to 32 HTTP connections and automatic retries.
- Source-specific video/audio formats and quality choices.
- Persistent download history with progress, speed, Stop/Remove actions and missing-file status.
- Windows Defender safety checks on Windows; completed transfers do not wait for long scans.
- Rounded light/dark themes and Vietnamese/English interfaces.
- Browser integration with the extension ZIP included alongside HDM and an installation guide inside Preferences.
- Proxy controls, startup/background settings and verified in-app updates.

Install the Windows EXE or drag the macOS app to Applications. Click the HDM logo to open Preferences.
Select your installed browser to follow the extension setup steps; no separate extension download is required.

Transfer speed depends on the source server, network and disk. A completed safety scan does not guarantee a file is harmless.
The extension requires Developer mode and is not yet listed in browser stores. DRM-protected sources are unsupported.
Windows packages are not Authenticode-signed and macOS packages are ad-hoc signed, not notarized.
Update metadata is signed separately with Ed25519.

See the [user guide](https://github.com/hngoos/hngoos-download-manager/blob/main/docs/USAGE.md)
and [platform details](https://github.com/hngoos/hngoos-download-manager/blob/main/docs/PLATFORMS.md).
