# HDM v0.1.0

**hngoos-download-manager** is a desktop download manager for Windows 10/11, 64-bit, with optional Chromium browser integration.

[**Download for Windows**](https://github.com/hngoos/hngoos-download-manager/releases/download/v0.1.0/HDM-Setup-0.1.0.exe?build=chromium-20261106) · [**Get the browser extension**](https://github.com/hngoos/hngoos-download-manager/releases/download/v0.1.0/HDM-Browser-Extension.zip?build=chromium-20261106) · [**Installation guide**](https://github.com/hngoos/hngoos-download-manager/blob/main/docs/USAGE.md)

## Highlights

- **Resumable downloads:** 1–32 HTTP/HTTPS connections, verified mirror downloads, expired-link replacement, destination changes, queueing, and scheduling.
- **Batch workflows:** import Excel/CSV/TXT, preview and edit rows, rename entries in bulk, and export per-row reports.
- **Video and audio:** yt-dlp integration, source-format choices, playlists/subtitles when available, and local staging before completed media is delivered.
- **Media tools:** trim, join, convert to MP4, extract audio, and compress with two-pass target-size checks while preserving the original.
- **File checks:** checksums, quarantine, Windows Defender/Authenticode tools, bounded ZIP/RAR/7z inspection, and hash lookups on three services.
- **Documents:** capture web pages as PDF/PNG, redact PDF regions, and try opt-in seller invoice capture.
- **Chromium integration:** Chrome, Cốc Cốc, Edge, Brave, and Opera; native messaging, optional download handoff, HLS/DASH detection, and experimental content filtering.
- **Desktop utilities:** torrent file selection and progress checkpoints, system tray operation, sleep prevention, and a cancellable shutdown countdown.

## Install

Run **HDM-Setup-0.1.0.exe** to install the application and browser bridge. For browser integration, extract **HDM-Browser-Extension.zip**, select **Load unpacked** in your browser, and choose the folder containing `manifest.json`. Register its extension ID in HDM's **Trình duyệt** (Browser) page.

If you used an earlier preview, install the current package, reload the extension from the new ZIP, and check its native connection. The desktop interface is currently in Vietnamese; documentation is available in English.

## Release status

This is an early release. Invoice capture and content filtering are experimental, and website compatibility depends on the source and your access permissions. The extension installs manually and is not published on the Chrome Web Store. See the [feature reference](https://github.com/hngoos/hngoos-download-manager/blob/main/docs/FEATURES.md) for verified behavior and limits.

Update metadata is signed with Ed25519; the Windows installer is not Authenticode-signed. These are separate mechanisms.

The public repository now includes the application source, extension, tests, and development tools alongside the documentation. Source access is governed by LICENSE. Download the installer and extension ZIP above for installation.
