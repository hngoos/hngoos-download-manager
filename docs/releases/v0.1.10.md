# HDM v0.1.10

- Filter downloads by **All · File · App · Video · Music · Image · Archive · Other**.
- Open **Info** with the circular icon at the top right; change **Appearance** and **Language** in its menu.
- View live download/upload rates at the bottom left and choose **HIGH**, **MEDIUM** or **LOW** bandwidth.
- Rounded panels, buttons and fields use bundled Morphicons assets with light and dark themes.
- Paste a link and press **Enter** for inline filename, destination and source-specific options; click **Download** to start.
- Use **Check Safety** beside completed files for local checks, Windows Defender and optional VirusTotal reports. VirusTotal requires a personal API key; uploading a file requires separate confirmation.
- Includes the Windows update handoff fix for missing Python DLL errors.

Choose your operating system's installer. Mobile is coming soon.
