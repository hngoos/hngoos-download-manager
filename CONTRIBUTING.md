# Help With Localization

Help make HDM accessible in more languages. Here is how to contribute:

1. Fork this repository.

2. Translate user-facing text or documentation into your language.

3. Keep file paths, placeholders, element IDs and code behavior unchanged.

4. Open a pull request with the language name and a preview of your changes.

You can find text to translate in these locations:

```text
src/hngoos_dm/app.py
src/hngoos_dm/batch_ui.py
src/hngoos_dm/dialogs.py
browser-extension/*.html
browser-extension/*.js
README.md
docs/
```

[HDM Translation Guidelines](docs/LOCALIZATION.md)

For code setup, testing and packaging, see the [Development Guide](docs/DEVELOPMENT.md).
