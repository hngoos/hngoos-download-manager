# Security Policy

If you find a security issue in HDM, please email [1hngoos@gmail.com](mailto:1hngoos@gmail.com) or submit a [private vulnerability report](https://github.com/hngoos/hngoos-download-manager/security/advisories/new). For ordinary bugs, use the [Issues tab](https://github.com/hngoos/hngoos-download-manager/issues).

Please keep vulnerability details and personal data out of public issues.
